# The name "Wish Engine": preliminary research (17 November 2026)

> **This is preliminary web research, not a legal opinion.** A trademark attorney or lawyer must check trademark availability in the official databases.

## Findings

- **No game engine with the same name was found.** A web search did not show a published engine, library or GitHub project called "Wish Engine". The near results are unrelated:
  - *Wish*, an old cancelled MMO (Mutable Realms; it used Gamebryo);
  - small games with "Wish" in the name;
  - a Shopify app called "Wishlist Engine".
- **No trademark registered exactly as "Wish Engine" appeared in the search.** There are close and strong marks, though:
  - **ContextLogic Inc.** (the shopping app *Wish*): many **WISH** registrations in software classes (9, 38, 42). Example: registration no. 6142756 of 1 September 2020, for downloadable shopping software and search engine software.
  - **Wish US Holdings LLC**: applications for software starting with WISH.
  - **Wish Genie Limited**: WISH GENIE (software).
- **Domain names:** the search showed no site for `wishengine.com` and `wishengine.io`. This does not mean they can be bought; check with whois.

## Assessment

There is no direct clash in the game engine field. Because the word "WISH" is a registered mark of another company in software classes, the risk of an objection for likelihood of confusion cannot be ignored. An expert must assess this risk.

## Recommended steps (yours)

1. **Ask a trademark attorney:**
   - a similarity search for "WISH ENGINE" in classes 9 and 42;
   - in the TÜRKPATENT, EUIPO and USPTO (Trademark Search) databases.
2. **Domain names:** check whois for `wishengine.com`, `.io`, `.dev`, `.org`.
3. **If an objection comes up:** a name change is a small job on the code side.
   - The `wen` command and the `wish_` crate prefix are internal names, not visible from outside.
   - The visible name appears in the texts of the editor, the welcome screen and the documents.
