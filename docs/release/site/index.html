Wish Engine

Dile, olsun. (Make a wish, and it is done.)

A free, open-source 3D game engine. Do everything by hand, or let an AI assistant do the same things. Both land in one history, and every step can be undone with a click.

Download for Windows Source code

Windows 10/11, 64-bit. Nothing else to install: the compiler is included. No revenue share, no telemetry. Interface in 12 languages.

A complete editor

Hierarchy, inspector, gizmos, prefabs; play, step by step, rewind.

AI cockpit

Show and tell. Every change appears live and can be undone on its own; a checkpoint before every task.

Game systems built in

Physics, lights and shadows, audio, animation, in-game interface, particles, 2D.

Code, without stopping

Game logic in Rust, sandboxed. On save, the game carries on with the new code without stopping.

Always the same

A scene plays out identically every time; replays and tests rely on this.

One-click export

Your game becomes a folder that runs on a computer without the engine.
