# Friction log

The M7 method (see [design/M7-showcase-game.md](design/M7-showcase-game.md) §3): every place where we get stuck while making a game with the engine is written here and fixed in the engine, not in the game. The same snag must not happen twice; every fix is protected by a test or an evaluation task.

Types: **tool** (missing tool or parameter), **message** (error message or hint is not enough), **docs** (wrong or missing documentation), **bug**, **API** (gap in the game code SDK), **performance**.

| No | What happened | Type | Cost | Fix | Status |
|---|---|---|---|---|---|
| F1 | I gave `wen do` readable (multi-line) JSON calls; it said "Line 2 is not valid JSON". The docs said "an array or one object per line"; the message pointed to the right place. | tool | 1 try | `wen do` now reads JSON objects written one after another (even when they span lines) | fixed |
| F2 | The new project's `CLAUDE.md` says nothing about physics, audio, interface, particles, 2D or animation; an agent can only find that they exist by guessing with `docs_search`. | docs | (estimated) a few searches | A "Game systems" section in the `CLAUDE.md` that `wen new` writes: the components of each system and the tool to observe it | fixed |
| F3 | While a session was open, `entity_get` read the scene file (the player looked like it had never moved); `sim_step`, however, uses the single open session by itself. The mismatch wasted one run. | message | 1 run | While a session is open, a `scene_not_session` note (the open sessions and their ticks) is added to the answer of `entity_get`/`entity_query` when they read without a `session`; the project guide says it too | fixed |
| F4 | While a character walked on flat ground, `CollisionStarted`/`CollisionEnded` came every few ticks (11 pairs in 40 ticks): the controller holds the capsule a thin gap above the ground, so contact kept starting and ending. Noise for game code that relies on contact events. | bug | — | Character colliders get a contact margin of twice the controller gap (`contact_skin`); test `a_walking_character_touches_the_ground_once` | fixed |
| F5 | I wanted to put a jump/collect sound in the game: there is no way to make a sound (or picture) file with the tools, and no download either. An agent stops here or makes a silent game. | tool | work stops | New tool `asset_create` (the 25th tool): `.wav` (wave, pitch slide, length, decay; deterministic) or `.png` (filled, circle, ring, diamond, triangle); in the project guide; test `m7_tools.rs`. This slightly widens the 1.0 scope (small placeholder assets). | fixed |
| F6 | To play a sound from game code you need `PlaySound { clip, … }`; `clip` is an `AssetRef`, but the SDK docs do not say how to make one from a path, and the SDK has no helper (`AssetRef::from_text(text(...))` can only be found by reading the source). | API | guessing/searching | `asset("assets/sounds/jump.wav")` in the SDK (in the prelude); the sound example on the SDK page uses it | fixed |
| F7 | I wanted to read the game's `Game` resource (collected crystals) in a session: `entity_query with: ["Game"]` said "no such component"; no tool read the value of a resource (only `until` conditions could see it). | tool | 1 try, no way out | A `resources` parameter on `entity_get` (scene and session; defaults the engine uses when the world has none); when a resource name is asked as a component, the hint says so; test `m7_tools.rs` | fixed |
| F8 | In the showcase game, a player riding the lift fell behind and dropped when the lift sped up. The character controller of Rapier 0.36 follows the kinematic body it stands on by its velocity, and only partly (at 2 m/s the player stays at about 80% of the way); my first try (adding velocity or displacement) summed with that and carried twice as far. | bug | game cannot be finished | During character movement, platforms are turned into velocity-driven bodies and their velocities are zeroed (this closes Rapier's half tracking); the character is carried rigidly by the platform's **real displacement** in that step (also on a rotating platform), and its own movement is added on top. Test: exact on a platform that eases 6.5 m in 3 s (`a_moving_platform_carries_the_character_standing_on_it`) | fixed |
| F9 | In the quiz interface, the child boxes were laid out in alphabetical (id) order: the question fell below the choices. The `order` parameter existed on `spawn`, but nowhere did the docs say "interface order comes from this"; I noticed it by looking at the picture. | docs | 1 round | The doc comment of `UiNode`, the description of `edit_apply` and the recipe page say the ordering | fixed |
| F10 | A test file I wrote with Python's default encoding became invalid UTF-8 because of Turkish letters; `test_run` said "stream did not contain valid UTF-8", but the hint only said "check that the file can be read". | message | 1 round | On invalid UTF-8 the hint names the encoding ("save as UTF-8, without BOM") | fixed |
